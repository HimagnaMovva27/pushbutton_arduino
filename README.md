# Push Button Control using Arduino

## Description

This project demonstrates how to use a push button with Arduino to control an LED. When the button is pressed, the LED turns ON, and when released, it turns OFF.

## Components Used

* Arduino Uno
* Push Button
* LED
* Resistors
* Jumper wires

## Working

The push button acts as an input device. When pressed, it sends a HIGH signal to the Arduino, which then turns ON the LED. When the button is released, the signal becomes LOW, turning the LED OFF.
